# TriNetra — Agentic Security Platform

> **Version 1.0 — July 2026** · Public product documentation

TriNetra is SecurityBoat's agentic cybersecurity platform. It combines AI-driven
automation with human expertise across five integrated modules that cover the full
security lifecycle — from continuous exposure discovery through offensive validation
to risk governance.

---

## Products
