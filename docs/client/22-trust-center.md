# Trust Center (Client View)

The **Trust Center** is where prospects, customers, and auditors request access to your security and compliance documentation. It centralises SOC 2 reports, ISO 27001 certificates, penetration test summaries, sub-processor lists, and other due-diligence artefacts behind a governed access gate.

---

## How It Works

1. **Requesters visit your Trust Center** — they see a catalogue of available documents
2. **They submit a request** — specifying which documents they need and why
3. **You review and approve or deny** — through the Trust Center dashboard
4. **Approved requesters gain time-limited access** — documents are viewable for a configurable window

---

## Dashboard Overview

The Trust Center dashboard shows:

| Metric | Description |
|---|---|
| Pending Requests | Requests awaiting your review |
| Approved Requests | Active access grants |
| Expired Access | Past grants that have lapsed |
| Documents Available | Number of compliance artefacts published |

---

## Managing Requests

### Reviewing a Request

Each request includes:

| Field | Description |
|---|---|
| Requester Name | Person or organisation making the request |
| Company | Their organisation |
| Documents Requested | Which specific documents they need |
| Reason | Business justification (e.g., vendor assessment, audit preparation) |

### Approving or Denying

- **Approve** — the requester receives a secure link with time-limited access
- **Deny** — provide a reason (e.g., request outside scope, requester not verified)

## Documents You Can Publish

| Document | Typical Audience |
|---|---|
| SOC 2 Type II Report | Enterprise prospects, auditors |
| ISO 27001 Certificate | Compliance teams, regulators |
| Penetration Test Summary | Security-conscious prospects |
| Sub-processor List | GDPR/DPA compliance reviewers |
| Business Continuity Plan | Enterprise risk teams |
| Incident Response Policy | Due diligence questionnaires |
| Data Processing Agreement (DPA) | Legal and procurement teams |

---

## Best Practices

- **Keep documents current** — expired certifications or outdated reports erode trust
- **Set reasonable access windows** — 7–30 days is typical for most requests
- **Review pending requests promptly** — slow approvals can delay sales cycles
- **Use the denial reason field** — clear explanations help requesters understand and re-apply if needed
