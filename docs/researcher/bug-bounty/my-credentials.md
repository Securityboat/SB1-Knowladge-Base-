# My Credentials

**My Credentials** lists the test accounts assigned to you for Bug Bounty programs and the status of your credential requests — *"Test accounts assigned to you for bug bounty programs, and the status of your requests."*

To open it, click **My Credentials** in the sidebar. You request credentials from a program's **Scope** tab — see [Scope → Test credentials](detail/scope.md#test-credentials).

---

## Assignments

| Column | What it shows |
|--------|---------------|
| **Program / asset** | The program (linked) and the asset the credentials belong to |
| **Roles** | The account roles in the set (for example *admin*, *user*) |
| **Status** | **Active**, **Released**, or **Revoked** |
| **Assigned** / **Ended** | When the assignment started and ended |
| **Actions** | **Reveal credentials**, **Report issue**, and **Release** |

- **Reveal credentials** shows the usernames, passwords, and notes. They hide automatically after a short countdown, when you switch tabs, or when you leave the page.
- **Report issue** tells the program team that a credential does not work.
- **Release** ends your access immediately: *"You lose access to the credentials for this asset immediately and cannot view them again. Release when you have finished testing."*

If credentials cannot be revealed, the row explains why: *Access released/revoked*, *Program paused — credentials cannot be viewed*, *You no longer have access to this program*, or *Credentials unavailable*.

## Requests

| Column | What it shows |
|--------|---------------|
| **Program / asset** | Where you asked for credentials |
| **Reason** | What you wrote in the request |
| **Status** | **Pending review**, **Approved — waiting for credentials**, **Credentials assigned**, **Rejected** (with the reason), or **Cancelled** |
| **Submitted** / **Decision** | When you asked and when it was decided |
| **Actions** | **Cancel** while the request is still open |

A request can be cancelled automatically if you no longer meet the program's requirements.

## Reported issues

Each issue you reported shows its category, your message, its status (**Open**, **Acknowledged**, **Resolved**), and the review note once resolved.

---

## Troubleshooting

| Symptom | Cause / Fix |
|---------|-------------|
| **"No credentials assigned"** | Request credentials from an active program's Scope tab. Approved requests appear here. |
| **Reveal credentials is missing** | The assignment ended, the program is paused, or you lost access. The row shows the reason. |
| **My request was rejected** | Read the rejection reason, adjust your justification, and submit a new request. |
