# Feedback (Researcher View)

The **Feedback** module lets you report bugs or request features directly from the platform. Submissions are sent to the SecurityBoatOne issue tracker for review.

---

## Submitting Feedback

1. Click the **Feedback** button in the sidebar.
2. A dialog opens with the following fields:

| Field | Description |
|---|---|
| Type | Choose **Bug** to report an issue, or **Feature Request** to suggest an enhancement |
| Title | A short, descriptive summary of your report |
| Severity | Select the impact level: Low, Medium, High, or Critical |
| Description | Detailed explanation of the issue or feature request |
| URL | Auto-filled with the current page URL (editable) |
| Console excerpt | Optional — paste any browser console errors you encountered |

3. Click **Submit** to send the report.

---

## When to Use as a Researcher

| Scenario | Type |
|---|---|
| A finding shows incorrect severity in the UI | Bug |
| Agentic Pentest discovery feed is not updating | Bug |
| You need a new filter or sort option in the findings list | Feature Request |
| The sign-off workflow is missing a step you need | Feature Request |
| Ask Ish returns irrelevant or incorrect responses | Bug |

---

## Best Practices

- **Be specific** — include steps to reproduce bugs, expected vs actual behaviour
- **Attach context** — the URL field automatically captures the page you were on
- **Use Console excerpt** — if you see errors in your browser's developer console (F12), paste relevant lines here
